## 已实现的行为

- 学习会话采用阅读中、练习中、结果页三个位置，以及进行中、已暂停、已结束三个状态。新流程无需填写复述、跳过原因、学习依据或总结。
- 阅读内容复用课程大纲和复习全书；练习复用现有 review、真实作答和 SM-2。每批最多 5 题，重复开始复用同一会话和批次，下一批排除本会话已答题。结束会话保留真实学习结果。
- 结果页由 learning-records 投影真实作答：区分首答、订正、待评分、未完成和去重覆盖，复习时间取现有排程。
- 大纲阅读、学习会话和完整阅读编辑器共用配图能力。用户可主动“画图解释”，也可在单次文字讲解中勾选“本次允许配图”。文字先保存，图片作为独立任务处理。
- 图像使用独立服务端 HTTP 能力、统一 Jobs 和持久请求回执；同一请求重放不会再次生成。已生成但正文保存失败时，只重试保存；请求结果未知时需要用户明确发起新生成。
- 图片以不可变资源存放在学习库中，正文仅持有资源引用。受控读取、历史、备份还原、分包和 Markdown 文件夹导出均携带资源；原嵌入图片仍可读取。
- 旧会话中的复述和笔记保留，成功进入新写入流程时升级；旧 pause 接口继续兼容。

## 模型配置

文字验收使用 `gemini-3.8-flash-high`，图片验收使用 `gpt-image-2`，地址取用户指定的本地 OpenAI 兼容服务。认证仅由进程环境提供，未写入源码、文档或 Git。

服务端配置项为 `STUDY_API_KEY`、`STUDY_BASE_URL`、`STUDY_MODEL`；图片可单独设置 `STUDY_IMAGE_MODEL`、`STUDY_IMAGE_BASE_URL`、`STUDY_IMAGE_API_KEY`，地址和认证默认继承文字配置。图像 HTTP 预算 300000 ms，无上游自动重试。模型返回的真实格式决定资源 MIME。

| 裁定 | 原因 | 代价与限制 |

| 付费回执复用既有原子 JSON 写入设施，排除便携备份 | 任务清理不能消除重放约束，避免还原历史重放付费请求 | 跨机器不迁移旧机器的进行中付费状态 |
