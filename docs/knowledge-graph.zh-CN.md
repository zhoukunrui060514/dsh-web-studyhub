# 资料知识图谱

“知识图谱”从当前学习库的用户资料提取概念、关系和逐字引文。它使用独立的 knowledge 组件，不需要先创建题组，不生成卡片、草稿或答题记录。原有题组知识结构视图仍可使用。

## 构建与更新

打开每日学习中的“知识图谱”，点“构建／更新”，选择资料并提交。支持导入文档、手动文本及音频转写的资料；目录清单、课程库存、系统生成内容和题库派生文本不参与自动构建。文档只处理当前版本。课程分组变化更新筛选归属，不重新调用模型。

自动构建默认关闭。开启后处理新导入的资料及后续内容变化，不扫描所有历史资料。用“补建已有资料”明确处理旧资料。关闭开关会取消尚未接单的自动意图，已接单任务可在“任务”中取消，手动任务不受影响。

构建通过 DSH 的统一后台任务执行。显示“等待模型配置”或“等待 DSH 后台执行器”表示意图已保存，尚未接单，没有伪造运行中的任务。稍后在具备模型和执行器的 DSH 会话中打开学习库即可恢复未接单意图。预览环境没有原生执行器，只能显示等待状态。宿主重启后已接单但中断的任务不会被当成仍在运行，需要明确重试。

每份资料完成后独立发布；失败或取消不会发布半份图谱。部分完成任务重试时跳过已经完成的同版本资料。原文在提取期间发生变化或被归档时，旧结果不会发布为当前版本。

同一份 PDF 后续补充导入页也会更新可读内容指纹，触发重新提取；原始文档版本仍用于引用定位。重试与新任务共享库级并发限制，不会抢占其他任务的资料。

提取时模型从原文片段目录选择引用编号，由服务端绑定原文及 UTF-16 位置。未知编号或不一致的引文会被拒绝。结构化结果无效时最多进行一次计量的纠正调用，仍不通过则该份资料失败且不发布。

## 探索与证据

用课程多选、资料筛选和搜索定位概念。全局最多显示 300 个节点、600 条关系，页面显示可见数量和总数；点节点查看一跳邻域，再继续展开或返回。画布支持缩放和平移，也提供可用键盘操作的节点与关系列表。

节点和关系详情列出定义、条件、方向与原文。`asserted` 表示资料直接陈述，`inferred` 表示基于资料的推断。多个来源的不同条件与矛盾分别保留。相同名称不会自动证明两个概念同义；只有证据支持的定义相容才复用概念，歧义由人工合并建议处理。人工修订独立保存，后续提取不覆盖它。

“在原文中查看”使用来源 ID、版本及 UTF-16 起止位置定位。旧版本、归档或删除的来源会显示原因，不会按相同文件名跳到别的资料。

## 节点、关系与链路问答

在详情中针对当前内容提问，或从节点开始按顺序选择最多 12 条相连关系，再针对链路提问。反向查看保留关系的真实方向；相连关系不代表因果可传递，也不代表净效应。

问答只用当前筛选内的有效资料证据，最多发送最近 6 轮成功历史与 24000 字符原文预算。引用 ID 必须来自实际提供的证据，未核验引用不会成为可打开的来源。无直接资料依据的解释会标为“补充解释／资料未直接说明”。模型仍可能理解错误，应结合引文判断。

会话按学习库、目标和筛选保存；关闭再打开会恢复历史。资料变化后历史仍保留，并标出旧版本或不可用引文。失败保留问题以便重试，提问不会重新构建图谱。

## 开发验收

`npm run qa:knowledge -- --lang zh --port 3198 --model-port 4198` 使用 `output/qa` 中带 knowledge 后缀的独立 DSH_HOME 与学习库。机器报告和截图在 `output/qa/knowledge-dsh`。确定性模型验证流程，不代表真实提取质量。

可通过运行时环境变量 `STUDYHUB_KNOWLEDGE_KEY`、`STUDYHUB_KNOWLEDGE_URL` 并添加 `--real-model` 验证指定的 `gemini-3.8-flash-high`；不要把密钥写入仓库。该命令同样只使用隔离库。

为整组本地 PDF 验收添加 `--materials-only --materials-dir "包含PDF的目录"`，仍会从源码在专用隔离实例部署，逐份导入、提取并校验原文位置及原始文件 SHA256。逐资料进度保存在验收输出目录的 `materials-progress.json`，资料本身不进入 Git 仓库。

模型接口恢复后可添加 `--reuse-home`，更新私有测试插件并接着使用原验收库，保留已完成的资料版本。所有 PDF 都完成后才会将真实模型验收报告为成功。
