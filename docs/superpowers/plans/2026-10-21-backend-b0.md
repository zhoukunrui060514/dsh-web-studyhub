# StudyHub B0：课程范围与兼容基线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 为五空间学习闭环建立一致的课程范围，并保留当前界面和 Agent 动作的兼容性。

**Architecture:** 复用 StudyRuntime、课程索引、课程层级和活动规则。增加无 I/O 的范围解析器，首先作为内部共享契约；修复现有 focus 更新语义，不在本阶段建立新的空间后端或迁移业务数据。

**Tech Stack:** Node.js >=22.19、ES modules、node:test、现有 StudyService/Store v4，无新增依赖。

**Spec:** [后端学习闭环设计](../specs/2026-10-21-backend-learning-loop-design.md)，重点 §7、§9、§10 B0。

## Global Constraints

- 前端开发暂停；本阶段不修改 ui/，不替换当前界面调用的动作。
- 在现有 `studyhub-redesign` 工作区执行，保留 S1 未提交改动及现有暂存内容。
- 真实 DSH 与真实学习库不作为开发、迁移或验收目标。
- 新增纯函数不得调用模型、文件系统或宿主服务；验证使用隔离临时库。
- `'*'`、空字符串、null 分别保持“全部”“未分类”“恢复默认”语义；省略 course 必须保留原选择。
- 数据与业务状态保留；B0 不变更 Store 版本，不迁移资料、会话或题库。

## Review Focus

1. 选择全部课程后仅改 mode、role、jd 或 targetTopics，不能丢失聚合范围（任务 1）。
2. 未分类不能被当作默认课程；空库的 null 默认应安全为空（任务 1、2）。
3. 父课程包含关系必须按完整路径段，TCP/IP 不得误判为父子课程（任务 2）。
4. 重命名后的稳定 ID 和旧别名应指向同一课程；隐式父路径不能伪造 ID（任务 2）。
5. 聚合范围与显式查看未激活课程的语义应有区别；解析过程不得修改状态（任务 2、3）。

## Task 2：统一课程范围解析器

**Files:** Create `lib/course-scope.js`；Create `tests/learning-scope.test.mjs`。

**Interfaces:**

- `resolveLearningScope(state, scope) -> ResolvedScope`，scope 只能是 `{kind:'all'}`、`{kind:'unassigned'}` 或 `{kind:'course',courseId,includeDescendants?:boolean}`；后者默认包含子课程。
- `resolveLegacyLearningScope(state, value) -> ResolvedScope`，value 为 `'*'`、`''`、null/undefined 或已知课程名称/别名/隐式父路径。null/undefined 按现有 currentCourse 默认策略解析；保存的 `'*'` 因此仍得到全部范围。
- `ResolvedScope = { kind:'all'|'unassigned'|'course', courseId:string|null, path:string|null, includeDescendants:boolean, courseIds:string[], activeCourseIds:string[] }`。all 的 path/courseId 为 null；unassigned 两个 ID 数组为空；隐式父路径 kind 为 course、courseId 为 null、path 为真实路径，成员是实际课程 ID。
- 不进行课程 active 筛除：courseIds 是完整成员，activeCourseIds 是当前有效成员。显式选中停用课程仍可查看它；推荐/练习的消费者在后续阶段采用活动规则，B0 不改变既有推荐结果。
- 输入结构错误抛出 code=`invalid-scope`；未知课程抛出 code=`course-unavailable`。错误不修改 focus，也不创建课程。

- [x] **1. 写行为测试。** 使用真实 `courseIndex`/课程记录构造 A、A / child、Aardvark、TCP/IP、停用父课程及显式激活子课程。断言 all/unassigned、精确/包含子课程、空库、非法类型、未知 ID、重命名别名、隐式父路径和活动成员。对深冻结输入运行全部解析，确认无修改。

## 自审与后续
