接口：learning.records.query({scope,type?,limit?,cursor?})；learning.records.get({type,id})；learning.reinforcement.query({scope,limit?,cursor?})。type 为 session/run/attempt/note。默认 50、上限 200。游标绑定范围、类型和投影内容；失效明确报 records-cursor-stale。

记录查询不执行 reconcile、不生成总结。摘要只含身份、时间、课程、结果与回链，不载入整段笔记/会话正文；get 返回单条既有记录。删除题组后历史记录课程未知，不冒充未分类。弱题排除归档/暂停题，显式查询可查看未激活课程，不新增掌握度状态。

Review Focus：历史题目删除、课程重命名、同一题不同 run 的回链；跨范围游标；总结后置调用失败；可选模块缺失；查询无写入。
