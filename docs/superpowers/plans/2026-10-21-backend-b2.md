# B2 Fixed Learning Sessions Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in the current session; TDD per task and one independent review after implementation.

**Goal:** 固定四步会话串接现有练习事实，保护原文、人工内容和旧学习流。

**Architecture:** 新 learning-session context 拥有 learningSessions；study 继续拥有 runs/attempts，跨域事务原子创建关联。纯目标解析和状态机在根级模块，避免私有跨 context 依赖。

**Tech Stack:** Node 22 ESM、现有 StudyRuntime/Store、node:test，无新依赖。

**Spec:** ../specs/2026-10-21-backend-b2-design.md 及后端闭环设计 B2。

## Global Constraints

- 前端暂停，S1 既有改动和已暂存删除保留，不操作真实 DSH/学习库。
- 练习评分、attempt、排程只复用 study；不以流程完成声明掌握。
- 每条会话 schemaVersion:1，单课程稳定 ID，version 必填；原文变更不能覆盖人工记录。
- 模型不用于此阶段；缺讲解/缺题如实呈现，允许显式跳过。

## Review Focus

- 并发/重放不会重复创建会话、run 或推进两步。
- 切换 focus、课程改名与两会话相同练习范围不扰动运行中目标。
- 无题、未答完和跳过不冒充练习完成。
- 扩展集合重开、备份、旧复杂流程导出保持内容完整。
- 依据过期、目标删除与 version 冲突有明确结果，旧作答保留。
